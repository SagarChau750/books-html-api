# Assignment submission

**Option selected:** 1 — Reverse-engineer an API.

I built a Python/FastAPI service that converts the public Books to Scrape HTML
catalogue into JSON APIs for listings, book details, categories and bounded title
search. It includes input validation, source URL restrictions, robots checking,
request pacing, caching, bounded retries and explicit error handling.

The repository includes setup/run instructions, interactive API documentation,
offline regression tests and a live end-to-end test script. Search responses state
their page coverage rather than implying an exhaustive result. LIMITATIONS.md
explains the source's fictional data, HTML fragility and the appropriate long-term
fix: a supported publisher API or authorised structured data feed.
